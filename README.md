# AskAnina for Nextcloud

AskAnina is a personal assistant: today, calendar, trips, reminders, tasks and contacts in one place.
This repository holds the Nextcloud app: a thin wrapper that shows the AskAnina web app inside
Nextcloud, with Nextcloud's navigation and an "AskAnina Today" Dashboard widget.

* App id: `askanina`, at `/index.php/apps/askanina/`
* Sign in with your AskAnina account; the app talks to the AskAnina service (https://askanina.com).
  Appointments are sealed end to end: the Nextcloud server cannot read them.
* Nextcloud 30 to 36.

The release archives in the Nextcloud App Store also contain the built AskAnina web app (`js/app/`).

* Website: https://askanina.com
* Support and bug reports: https://askanina.com/?p=support
* Privacy: https://askanina.com/privacy
